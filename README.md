# WanderMore landing page

## Files
- `index.php` — page structure and PHP arrays for hero slides and destination cards
- `style.css` — responsive layout and visual styling
- `script.js` — carousel controls, autoplay, destination slider, and mobile navigation

## Run locally
1. Install PHP if needed.
2. Open a terminal in this folder.
3. Run: `php -S localhost:8000`
4. Visit `http://localhost:8000`

Images are loaded from Unsplash, so an internet connection is required for the photos and Google Fonts.
Change the `$slides` and `$destinations` arrays in `index.php` to customize the content.
